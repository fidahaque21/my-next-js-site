My project name is FITLOG 

FITLOG is a simple fitness website where you can work out at home without any equipment. It offers videtext-guided routines for all levels, from beginner to advanced, and users can track their own progress.
Here the technologies
Next.js
Tailwind CSS
React toastify

 5 key features of the project:-
1. Users can add in today's plan
2. Users can save for later
3. Users can see the workouts 
4. Users can mark as done
5. Users can also remove worout from today's plan & saved
